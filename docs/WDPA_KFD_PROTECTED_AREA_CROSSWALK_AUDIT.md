# KFD register and WDPA secondary crosswalk audit — 20 September 2026

## Decision

**Source-level comparison reproducible; statutory and secondary protected-area geometry NOT admitted.** The linked live [complete-ID run](https://github.com/abhijith-sivaprasadan/kerala2040/actions/runs/35533796181) queried the UNEP-WCMC ProtectedSites WDPA FeatureServer (points layer 0; polygons layer 1) in the broad 74.75–77.55 E, 8.15–12.9 N envelope. The service reported **four polygon feature IDs and four point feature IDs**, and the fetched source pages reconciled exactly against both counts. The point records are **Nilgiri, Ashtamudi Wetland, Sasthamkotta Lake and Vembanad-Kol Wetland**. The four polygon records are **Western Ghats, Ranganathittu Bird Sanctuary, Vembannur Wetland Complex and Suchindram Theroor Wetland Complex**. No polygon name uniquely matched any of the **25** KFD core park/sanctuary/community-reserve records. A successful HTTP request or green CI does **not** mean all 25 polygons were found or that the dataset is a substitute for a notified boundary.

An independent [count-and-name diagnostic run](https://github.com/abhijith-sivaprasadan/kerala2040/actions/runs/35533590032) found the same four envelope IDs in each MapServer and FeatureServer layer and regardless of whether the IND ISO field was used; unfiltered worldwide service counts were 307,019 polygon and 7,747 point records. This confirms the original one-page four-feature result was **not fixed by simply paginating the exact same query**. It does **not** prove that any named Kerala park is missing from every Protected Planet release or that there are only four protected areas in Kerala. Only this endpoint, envelope and dated result were tested. The envelope includes neighbouring states and is not a clip to the NWIC Kerala polygon.

The updated [KFD reference register](../configs/kerala_protected_area_crosswalk_2026.yaml) retains the older Kerala Forest Department listing as name/category source. It uses the later **Kerala Economic Review 2025, volume II, Appendix 3.6.6**, published January 2026, to update numerical areas where the government tables differ. The especially consequential change is **Silent Valley National Park 89.52 km²**, not the older **237.52 km² Silent Valley wildlife-division figure**: the newer report identifies 148 km² of Bhavani Range as outside the national-park designation. Wayanad WLS 344.479, Idukki WLS 105.364, Shendurney WLS 172.403, Chimmony WLS 114.600, Kadalundi–Vallikunnu Community Reserve 1.538 and Periyar Tiger Reserve 925.675 km² are also retained with the older reported values alongside. Government source: https://spb.kerala.gov.in/sites/default/files/2026-01/ER%202025%20Volume%202%20Eng%20final.pdf (printed p. 130; PDF p. 153). Areas are descriptive reference numbers, **not geometry, a common non-overlapping union or an eligible-area total**.

## Admission limitations and next custodial acquisition

- Never buffer point records or substitute WDPA boundary polygons for original Kerala Forest Department gazette-linked polygons. No automatic name-substring join, no assumption that a worldwide polygon overlapping the rectangular Kerala envelope is a Kerala legal protected-area designation.
- Preserve original query and response bytes, source hash, count/ID reconciliation and unmatched names in a time-limited Actions artifact, not as a permanently republished authoritative GIS layer.
- Obtain current reserve forest, proposed reserve, vested forest, EFL, national park/sanctuary/community reserve boundaries and final ESZ boundaries separately from KFD/KSDI with notification ID, effective date, original CRS, revision date, survey accuracy and research/redistribution terms. Verify each polygon against legal schedules before any siting exclusion. See [forest source audit](../data/evidence/gis/forest_protected_area_source_audit_2026_09_20.json).
- `secondary_geometry_can_support_provisional_screening`, `statutory_boundary_verified`, `eligible_area_sq_km` and `capacity_ceiling_mw` remain respectively **false, false, null, null**. A future WDPA dataset with genuine unique matches requires a new dated independent geometry/legal audit; this run cannot silently become model-ready.
