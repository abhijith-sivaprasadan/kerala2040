# Contributing

Kerala 2040 is evidence-led. Contributions should improve data quality, physical realism, reproducibility or transparent scenario analysis.

## Requirements

- State the hypothesis/question before changing model logic.
- Cite the primary source for every external assumption where possible.
- Declare units explicitly.
- Add or update tests for calculation changes.
- Do not alter physics, costs, constraints or solver tolerances simply to obtain a preferred result.
- Distinguish observed facts, project assumptions and scenario choices.
- Never commit confidential, personal, security-sensitive or licence-restricted raw data.

## Pull-request checklist

- [ ] source/provenance updated
- [ ] units checked
- [ ] tests pass
- [ ] assumptions documented
- [ ] no hidden data files
- [ ] result interpretation does not outrun evidence
