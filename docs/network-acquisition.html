Source triage

What we can acquire automatically

The strongest public source is not SOS. It is KSEBL PSE's own Grid Map v3.2, dated 31 March 2026, which exposes feeder, substation, generating-station and district layers as static JavaScript/GeoJSON objects.

The useful discovery

The public Grid Map exposes Substations_18.js, in-service/proposed feeders at 33/66/110/220/320/400 kV, generating stations, district polygons, and public single-line-diagram links. SOS and TrAMS are login-gated, so this workflow does not touch them.

Run locally or let GitHub do it

GitHub Actions runs the collector on relevant pushes, manually on demand, and weekly. It archives raw pages/files, GeoJSON conversions, an SLD inventory, hashes and QA.

What this still cannot obtain

Historical substation MW/MVAr operating data are not exposed anonymously by the SOS/TrAMS login pages. This console will keep probing public sources, but it will not automate passwords, session abuse or access-control bypasses. For now, the public map closes topology/geography much more strongly than load chronology.
